# DreamQuest AI

Discover your future. Learn the skills. Level up your life.

## Stack
- Frontend: React + TypeScript + Tailwind CSS + Framer Motion + Recharts + Lucide
- Backend: Node.js + Express + TypeScript + Zod
- Database/Auth: Extensible API structure with auth endpoints and progress persistence hooks

## Run locally

### Backend
```bash
cd /home/runner/work/Project/Project/backend
npm install
npm run dev
```

### Frontend
```bash
cd /home/runner/work/Project/Project/frontend
npm install
npm run dev
```

The frontend proxies `/api/*` to `http://localhost:3001`.
